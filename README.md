# Portfolio Landing Page

Portfolio landing page statis untuk Muhammad Rizki Fahrurrozi yang siap dipublikasikan ke GitHub Pages.

## Struktur file

- `index.html` — halaman utama portfolio
- `project-harvest.html` — detail project publik 1
- `project-metro.html` — detail project publik 2
- `project-zenith.html` — detail project publik 3
- `styles.css` — styling utama
- `script.js` — script kecil untuk year footer

## Cara publish ke GitHub Pages

1. Push semua file ke repositori GitHub Anda.
2. Buka menu: `Settings` -> `Pages`.
3. Pilih sumber deploy: `Deploy from a branch`.
4. Branch: `main` atau branch default Anda.
5. Folder: `/ (root)`.
6. Save.
7. Tunggu beberapa menit untuk proses publish.

## Catatan

- Halaman ini dibuat untuk portfolio dan project showcase.
- Beberapa proyek ditampilkan sebagai `Public`, dan beberapa sebagai `Private` untuk kebutuhan portfolio yang lebih realistis.
- Anda dapat mengganti nama proyek, deskripsi, link repo, dan kontak sesuai profil Anda.
